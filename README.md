# تعريب Danganronpa V3: Killing Harmony

هنا تعريب Danganronpa V3، يشمل القصة والقوائم والمحاكمات والألعاب المصغرة، مع خطوط عربية وصور بنفس أسلوب اللعبة.

التعريب يحتوي على **3053 صورة تم تعريبها و576,578 كلمة**. ما قدرت أراجعها كلها بسبب ضخامة اللعبة، لكني متأكد إن التعريب هو الأفضل. وإذا لاحظت أي خطأ أرسل لي صورته عشان أعدله.

**التعريب:** [seven — @sevenlization](https://x.com/sevenlization)  
**النسخة:** Steam على Windows 64 بت · **حجم التحميل:** حوالي 659 MB.

## تحميل التعريب

[اضغط هنا لتحميل التعريب](https://github.com/79sk/Danganronpa-V3-Arabic/releases/tag/v2.0)

## وش يشمل التعريب؟

- نصوص القصة والحوارات والخيارات.
- القوائم والإعدادات والتعليمات.
- المحاكمات والأدلة والألعاب المصغرة.
- أسماء الشخصيات وألقابها وصور الواجهات واللافتات التي تم اعتماد تعريبها.
- خطوط عربية مع ضبط اتجاه الكتابة.

عدد الصور يشمل نسخها بأحجامها ومواضعها المختلفة والرموز المعدلة. عدد الكلمات للنصوص، ولا يشمل الكتابة داخل الصور أو النسخ التقنية المكررة.

## طريقة التركيب

التركيب
1. فك ضغط هذه الحزمة.
2. افتح مجلد الحزمة وانسخ محتوياته ال6 بجوار Dangan3Win.exe في مجلد اللعبة.
3. شغّل Sevenlization.exe،
 واختر 2 للتركيب
، وانتظر رسالة PASS.
4. شغّل اللعبة بالطريقة المعتادة.

الخيار 1 يفحص التوافق دون تعديل الملفات.
الخيار 4 يفحص ملفات التعريب بعد التركيب
